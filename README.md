# Weather Intelligence & Alert Center

تطبيق Python يجمع بيانات الطقس الحالية لمدينة معينة، يحللها، ويحوّلها إلى تنبيهات وتوصيات مفهومة، مع درجة ملاءمة (Comfort Score) توضح مدى راحة الطقس للمستخدم وسبب ذلك.

## المميزات

- جلب بيانات الطقس الحالية (الحرارة، الرطوبة، الرياح، الحالة الجوية) من OpenWeatherMap API
- حفظ سجل تاريخي (Snapshots) لكل عملية بحث بملف JSON
- حساب إحصائيات (المعدل، الأعلى، الأدنى) واتجاه الحرارة (Trend) من السجل التاريخي
- نظام تنبيهات وتوصيات مبني على Thresholds قابلة للتعديل
- **Weather Comfort Score**: درجة من 0-100 توضح مدى ملاءمة الطقس، مع شرح نصي لسبب الدرجة
- معالجة شاملة للأخطاء (مدينة غير موجودة، انقطاع اتصال، timeout)

## المتطلبات

- Python 3.10 أو أحدث
- مفتاح API مجاني من OpenWeatherMap (openweathermap.org/api)

المكتبات المطلوبة موجودة بملف requirements.txt:
- requests — للاتصال بالـ API
- python-dotenv — لقراءة مفتاح الـ API من ملف .env بأمان
- pytest — لتشغيل الاختبارات

## التثبيت والتشغيل

1. استنسخي المشروع:

git clone https://github.com/fatimasinan558-netizen/weather-intelligence-center.git
cd weather-intelligence-center

2. ثبتي المكتبات المطلوبة:

pip install -r requirements.txt

3. أنشئي ملف .env بمجلد المشروع الرئيسي وحطي بداخله مفتاحك الخاص:

WEATHER_API_KEY=هنا_مفتاحك

4. شغلي البرنامج:

python3 main.py

## مثال استخدام

اكتب اسم المدينة: Baghdad

--- بيانات الطقس ---
المدينة: بغداد
الحرارة: 28.95°C
الرطوبة: 30%
سرعة الرياح: 2.57 m/s
الحالة: سماء صافية

--- التنبيهات ---
لا توجد تنبيهات.

--- درجة ملاءمة الطقس (Comfort Score) ---
الدرجة: 100/100
السبب: الطقس مريح بشكل عام ولا توجد عوامل رئيسية تقلل من الراحة.

## بنية البيانات

كل سجل يُحفظ بملف data/snapshots.json بهذا الشكل:

{
  "city": "بغداد",
  "timestamp": "2026-09-03 01:21:54",
  "temperature": 32.95,
  "feels_like": 31.55,
  "humidity": 27,
  "wind_speed": 5.14,
  "condition": "سماء صافية"
}

تفاصيل أكثر موجودة بملف docs/data_dictionary.md.

## الميزة المميزة: Weather Comfort Score

يحسب البرنامج درجة من 0 إلى 100 توضح مدى ملاءمة الطقس الحالي، اعتمادًا على الحرارة، الرطوبة، الرياح، والأمطار. كل عامل يقلل من الدرجة حسب قواعد موثقة، ويعرض البرنامج شرحًا نصيًا واضحًا يوضح سبب ارتفاع أو انخفاض الدرجة.

## هيكل المشروع

weather-intelligence-center/
- main.py: نقطة تشغيل البرنامج، يربط كل الوحدات
- api_weather.py: جلب بيانات الطقس من API
- storage.py: حفظ وقراءة السجلات التاريخية
- analytics.py: حساب الإحصائيات والـ Trend
- rules.py: التنبيهات، التوصيات، و Comfort Score
- cache.py: الكاش
- data/: ملفات JSON للبيانات المحفوظة
- docs/: المستندات (Brief, Data Dictionary, إلخ)
- tests/: اختبارات pytest
- presentation/: العرض التقديمي والفيديو
- requirements.txt
- .env: مفتاح API (غير مرفوع لـ GitHub)

## تشغيل الاختبارات

pytest -v

يحتوي المشروع على 20 اختبار تغطي جلب البيانات، التخزين، التحليل، والتنبيهات.

## القيود المعروفة

- المفتاح المجاني من OpenWeatherMap محدود بعدد طلبات يومي.
- الإحصائيات والـ Trend تحتاج أكثر من سجل واحد بنفس المدينة لتظهر نتائج ذات معنى.
