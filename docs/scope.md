# Scope — Weather Intelligence & Alert Center

## Must Have (أساسي — لازم يكون موجود)

- جلب بيانات الطقس الحالية من API لمدينة يحددها المستخدم
- معالجة الأخطاء: مدينة غير موجودة، انقطاع اتصال، timeout
- حفظ كل عملية بحث كسجل تاريخي (Snapshot) بملف JSON
- حساب إحصائيات (average/max/min) من السجل المحفوظ
- منطق Trend بسيط لاتجاه الحرارة
- نظام Thresholds قابل للتعديل يولّد تنبيهات وتوصيات
- Decision Table لحالة وجود أكثر من تنبيه بنفس الوقت
- الميزة الإلزامية: Weather Comfort & Risk Score مع شرح نصي
- اختبارات pytest تغطي كل الوحدات الأساسية
- توثيق كامل (README + docs/)

## Nice to Have (إضافي — لو توفر وقت)

- Forecast لعدة أيام بدل الحالة الحالية فقط
- Charts باستخدام matplotlib لعرض تغير الحرارة عبر الزمن
- واجهة رسومية بسيطة (Streamlit) بدل الـ CLI
- Export لتقرير يومي بصيغة CSV أو نصي
- دعم مقارنة أكثر من مدينة بنفس الوقت
